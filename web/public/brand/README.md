# Home AI Core brand assets

These assets are the optimized project copies of the Home AI Core logo set.

## Runtime assets

- `logo-mark.webp` — compact mark used in the sidebar/header.
- `app-icon.webp` — square icon used on authentication screens and as the browser favicon.

## Brand variants

- `variants/logo-horizontal.webp` — wide logo/wordmark composition.
- `variants/logo-landscape.webp` — landscape logo composition.
- `variants/logo-stacked.webp` — stacked logo composition.

The original artwork is kept outside the runtime bundle; these WebP versions are optimized for shipping with the web UI.
