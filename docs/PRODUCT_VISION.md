# Home-AI — Product Vision

Home-AI — локальная расширяемая платформа для домашнего сервера. Базовая система должна оставаться управляемой локально и не зависеть от обязательных внешних облачных сервисов.

## Архитектурная модель

Платформа состоит из двух уровней:

### Home-AI-Core

Доверенный control plane:

- identity;
- users and permissions;
- policy/security;
- audit;
- jobs and events;
- module registry;
- system/hardware discovery;
- storage/network foundations;
- updates;
- Web shell.

### External modules

Функциональные возможности поставляются отдельно как изолированные Docker-модули. Модуль может быть добавлен, обновлён или удалён независимо от Core.

Core не должен знать бизнес-логику конкретного модуля и не должен хранить его доменные данные в собственной SQLite.

## Основные принципы

- local-first;
- минимальный доверенный Core;
- least privilege;
- явные permissions;
- auditable actions;
- модульная поставка;
- независимое обновление Core и модулей;
- amd64 и arm64 там, где это поддерживается модулем;
- отсутствие прямого доступа непривилегированного Core к Docker socket;
- возможность будущего multi-node orchestration без изменения базовых security contracts.

## Пользовательский опыт

Пользователь устанавливает Home-AI-Core один раз. После первичной настройки он открывает раздел модулей и выбирает нужные расширения. Core загружает совместимый подписанный/доверенный контейнерный образ, создаёт ограниченный runtime и показывает состояние модуля в общем интерфейсе.

Удаление модуля не должно ломать Core. Обновление Core не должно без необходимости обновлять все модули.

## Безопасность модулей

Каждый модуль:

- имеет стабильный ID;
- объявляет версию и совместимость с Core;
- объявляет capabilities и permissions;
- имеет отдельный persistent data directory;
- получает только необходимые mounts/network/devices;
- не получает root-доступ автоматически;
- не получает Docker socket;
- проходит lifecycle через Core/privileged helper;
- должен иметь health/status contract.

## Долгосрочная цель

Home-AI-Core становится стабильной платформой, поверх которой можно независимо развивать и распространять множество функциональных модулей без разрастания доверенного ядра.
