# Безопасное обновление Docker-модулей

Статус: draft PR #170, не развернуто на сервере.

Реализовано в ветке:
- отдельное задание module.update;
- отказ от замены контейнера обычной установкой;
- строгая проверка SemVer, совместимости и наличия health endpoint;
- сохранение предыдущего контейнера до завершения проверки;
- HTTP health-check новой версии из непривилегированного Core;
- восстановление предыдущего контейнера при ошибке запуска или health;
- фиксация новой версии в реестре после успешной проверки.

Перед выпуском остаётся:
- интеграционный тест на реальном Debian Docker node;
- резервное копирование /data перед несовместимыми миграциями;
- восстановление незавершённых операций после аварийного перезапуска;
- полные проверки безопасности официального каталога;
- обновление карты проекта и отдельный release после приёмки.

Без проверки на тестовом сервере PR сливать в main нельзя.
