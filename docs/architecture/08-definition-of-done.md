# Definition of Done

A roadmap phase is complete only when all of the following are true for its scope:

- architecture or API contract is documented
- implementation is present where the phase requires code
- automated tests cover the defined behaviour
- failure and rollback behaviour is defined
- security implications are reviewed
- logs and audit behaviour are defined
- user/admin documentation is updated
- third-party dependencies and licenses are recorded
- the result is reproducible on the supported Debian 13 baseline

A partially implemented feature is not treated as a completed roadmap phase.
