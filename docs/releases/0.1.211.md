
## Frigate в HomeAiCore

Frigate устанавливается отдельным модулем из официального `blakeblackshear/frigate`, без замены NVR. Версии обнаруживаются непосредственно в GitHub; OCI index, platform manifest и config проверяются по SHA-256 и архитектуре. Поддерживаемая серия: >=0.18.2 <0.19.0. Изменившийся после подтверждения digest отклоняется.

Обновление выполняется только вручную через Job Engine. Перед запуском новой версии сохраняется и проверяется вся конфигурация, включая SQLite DB/WAL/SHM. Неудачный запуск или ошибка registry commit возвращают предыдущий контейнер, конфигурацию и БД. Для прерванного обновления есть отдельная команда восстановления.

Веб-интерфейс включает снимки камер, события, клипы, состояние и редактор конфигурации. Из карточек модулей удалены лишние кнопки проверки обновлений — используется общая кнопка.

### Проверенный объём

- Linux amd64: реальный официальный контейнер 0.18.2, намеренно повреждённые YAML/SQLite, автоматический откат и восстановление прерванных транзакций.
- amd64 и arm64: реальные официальные OCI digest/config и сборки HomeAiCore.
- Тест транзакции использует index и platform digest одного официального образа; это не испытание ещё не опубликованной следующей версии.
- Не проверены пользовательские камеры и физическое arm64-устройство. Профиль CPU, без GPU/USB/host-портов.
- Видеозаписи не включены в резервную копию конфигурации. Их retention и независимое резервирование остаются отдельной ответственностью.

После установки Core: «Модули» → «Доступные» → «Frigate» → «Установить». Установка на работающий сервер и подключение камер требуют отдельного подтверждения владельца.

### Автоматическое меню установленных модулей

После установки Frigate появляется в левом меню автоматически. Запись остаётся при остановке или ошибке и показывает состояние; удаление модуля убирает её. Для старых manifest без навигации ядро формирует пункт из реестра. Пустая страница «маршрут недоступен» заменена страницей управления; у Home Assistant доступен переход в его интерфейс. Навигация фильтруется по правам, а Frigate и AI Agent доступны только администраторам модулей.
