## Полный штатный интерфейс Frigate

Вместо сокращённой страницы со снимками Core открывает оригинальное веб-приложение официального Frigate: Live, Review/History, Explore, Export, Settings, System, Logs и редактор конфигурации. Встроены исходные настройки камер, детекции, зон и масок; APIs/WebSocket/MSE/HLS/Range-загрузки не ограничиваются прежним небольшим списком.

**Переустановка Frigate не требуется.** Сохраняются текущий контейнер, камеры, конфигурация, архив, проверка digest, ручные обновления и откат. После обновления Core откройте Frigate в левом меню.

Интерфейс работает на отдельном HTTPS-origin (по умолчанию порт 8971) с той же сессией и сертификатом Core. Для доступа требуется `modules.manage`; порт 5000 контейнера не публикуется. Cookie/токены Core не передаются в контейнер, origin изолирован, запросы записи проверяются, выход из Core закрывает доступ. Есть отдельная вкладка для возможностей браузера, ограниченных iframe.

На изолированном стенде проверены оригинальный UI, реальное MSE-видео, запись/HLS, экспорт MP4 и Range-загрузка, настройки/Monaco, сохранение YAML, ограничения прав и отзыв сессии. Камера синтетическая; реальные камеры владельца и сервер не изменялись.

**Не включается автоматически:** GPU/USB/Coral, ICE/TURN-маршрут для WebRTC/двустороннего аудио, MQTT-брокер и платные функции Frigate+. Эти возможности требуют собственных устройств/конфигурации. Аппаратный профиль контейнера в этом выпуске не менялся.

При блокировке iframe откройте отдельную вкладку, проверьте доверие сертификату и доступность HTTPS-порта 8971. При конфликте порта настройте `HOME_AI_FRIGATE_UI_LISTEN`; Core продолжит работать даже при недоступном шлюзе.
